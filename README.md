**Study Slooth™** isn't just another study tool. 

**Study Slooth™** transforms learning for students because it crafts a unique study plan based on a student's individual learning styles, the type of content the student is learning, and the time for which a student wants to study for.

For teachers, **Study Slooth™** finally introduces a long-awaited classroom tool that facilitates classroom activities without gluing students to a screen and allows teachers to measure a student's understanding instead of an algorithm.
